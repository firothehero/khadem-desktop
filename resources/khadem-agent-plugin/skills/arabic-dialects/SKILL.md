# اللهجات العربية والعربيزي

## متى تُستخدم
عندما يكتب المستخدم بلهجة أو بحروف لاتينية (عربيزي)، أو يطلب محتوى بلهجة محددة (تسويق محلي، نصوص حوار، ردود خدمة عملاء).

## القاعدة الافتراضية
افهم اللهجة، وردّ بفصحى مبسّطة قريبة منها، إلا إذا طلب المستخدم الرد باللهجة أو كان السياق غير رسمي بوضوح فجاره بها.

## علامات تمييز سريعة
| اللهجة | علامات | أمثلة |
|---|---|---|
| خليجية | وش/شنو، أبي/أبغى، زين، الحين، ترى، چ/گ | «وش تبي الحين؟» |
| شامية | شو، بدّي، هلّق، كتير، منيح، هيك | «شو بدك هلق؟» |
| مصرية | إيه، عايز، دلوقتي، أوي، كده، مش، بتاع | «عايز إيه دلوقتي؟» |
| عراقية | شكو، أريد، هسّه، كلّش، زين، ماكو | «شكو ماكو؟» |
| مغاربية | واش، بغيت، دابا، بزّاف، مزيان، علاش | «واش بغيتي دابا؟» |

## العربيزي (الأرقام والحروف اللاتينية)
2 = ء/أ، 3 = ع، '3 أو 3' = غ، 5 = خ، 6 = ط، 7 = ح، '7 = خ، 8 = ق (أحياناً)، 9 = ص/ق، '9 = ض.
مثال: «7abibi kifak? 3ndi so2al» ← «حبيبي كيفك؟ عندي سؤال».
عند التحويل إلى العربية اكتب النص بالحروف العربية أولاً ثم أجب.

## تنبيهات
- الكلمة الواحدة قد تختلف معناها بين اللهجات («زين» = جيد في الخليج والعراق؛ «يعطيك العافية» شكر في الشام والخليج).
- تجنّب الصور النمطية والسخرية من أي لهجة.
- في المحتوى الرسمي أو المكتوب للنشر الواسع: الفصحى أسلم.
